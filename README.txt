AMU INFIRMARY — Prototype 0.1

使い方:
1. index.html をSafariまたは対応ブラウザで開いてください。
2. 「患者名簿」→「新規登録」からキャラクターを登録できます。
3. 登録内容と画像は、そのブラウザのIndexedDBに保存されます。
4. 「設定」からJSONバックアップを書き出し・復元できます。

注意:
- この試作品はローカル保存です。SafariのWebサイトデータ削除や端末変更でデータが失われる場合があります。定期的にバックアップしてください。
- 端末の「ホーム画面に追加」やオフラインPWA化は、HTTPSでの公開環境を用意した次の工程で対応します。
- 関係性・世界観・Spotify連携・資料保管庫は今後の追加予定です。
